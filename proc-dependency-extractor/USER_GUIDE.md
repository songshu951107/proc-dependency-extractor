# 存储过程依赖与血缘分析系统 · 功能使用说明

本系统用于解析数据仓库中的存储过程脚本和帆软报表，梳理表与表、字段与字段之间的血缘关系，并回答两个核心问题：

- **改了某张表/某个字段，会影响哪些下游表、存储过程和报表？**
- **某张报表上的某一列数据，最初是从哪张表的哪个字段加工来的？**

系统提供 Web 界面，左侧菜单包含六大功能模块，下面逐一说明。

---

## 一、导入脚本

**用途**：把存储过程脚本（Python `.py`）解析入库，作为后续血缘、影响分析的数据来源。

**操作方式**：
- 选择单个 `.py` 文件，或指定一个目录批量导入该目录下所有脚本。
- 解析时会自动识别：脚本头部说明、schema 变量映射（如 `CDM=etl.dwa_db_cdm`）、SQL 块、涉及的临时表与依赖表、字段映射关系。

> 导入后可去「存储过程列表」查看结果。重复导入同名脚本会覆盖旧数据。

---

## 二、存储过程列表

**用途**：浏览已导入的全部存储过程。

- 支持按名称搜索、分页浏览。
- 每条记录显示脚本名称、功能说明、更新对象、依赖表数量等概要信息。
- 点击某条记录进入「依赖表详情」。

---

## 三、依赖表详情

**用途**：查看单个存储过程解析出的细节。

- **依赖表清单**：该存储过程读取/写入了哪些表，区分临时表与正式表。
- **SQL 块**：按顺序展示脚本中的每一段 SQL，便于核对解析依据。
- **字段映射**：目标表字段 ← 源表字段的对应关系，含来源表达式（如 `T.acct_no`、`SUM(a.amt)`）。

---

## 四、血缘图

**用途**：以图谱形式直观展示某存储过程内部的表级数据流向。

- 节点为表，箭头表示数据从源表流向目标表。
- 可查看相邻表之间的 JOIN 条件、WHERE 过滤条件。
- 支持图谱视图与列表视图切换。
- 可对单张表递归追溯上游（最多 10 层）。

---

## 五、影响分析

**用途**：以某张表或某个字段为起点，分析它的上下游影响范围。

**第一步：选择分析对象**
1. 选择 Schema（数据层，如 FDM/ODM/CDM/PID）。
2. 选择表名（自动过滤临时表）。
3. 可选：选择具体字段 → 进入「字段级」分析；不选字段则为「表级」分析。

**第二步：选择分析方向**
- **下游（DOWNSTREAM）**：这张表/字段被哪些下游表/字段消费。
- **上游（UPSTREAM）**：这张表/字段的数据由哪些上游表/字段加工而来。
- **双向（BOTH）**：同时展示上下游。

**结果展示**：
- **统计栏**：影响字段数、涉及存储过程数、最大传播深度。
- **血缘图谱**：节点按层级（深度）分层显示，临时表会被穿透（不单独占层）。
- **传播链**：以文字形式列出 `源 → 目标` 的逐跳关系。
- **报表影响**（可选勾选）：分析该表被哪些帆软报表引用。
- **筛选工具栏**：可按 Schema 筛选、按表名关键字高亮、隐藏未命中节点。
- 点击节点/边可在右侧面板查看详情（字段、深度、存储过程、来源表达式）。

> 字段级分析会展示字段到字段的精确链路，并标注转换类型（直接引用 / 字面量 / 聚合 / 派生表达式）。

---

## 六、报表影响分析

**用途**：从报表视角出发，反查数据来源或追溯字段血缘。页面右上角「报表解析」可导入帆软报表文件（`.cpt / .frm / .xml`）。

提供四种查询模式：

### 模式 1：表级查询
**问题**：哪些报表用了某张表？
- 选 Schema + 表名 → 列出所有引用该表的数据集及所属报表。

### 模式 2：字段级查询
**问题**：哪些报表引用了某个字段？
- 选 Schema + 表名 + 字段 → 列出引用该字段的报表、数据集、来源表达式及单元格位置。

### 模式 3：口径查询
**问题**：某个业务口径（表头汉字，如"客户名称""利率"）出现在哪些报表的哪些列？
- 输入表头汉字（支持模糊匹配）→ 列出所有相关报表及字段映射明细，含源表、源字段。

### 模式 4：报表列溯源 ⭐
**问题**：报表上某一列的数据，最初来自哪张表哪个字段，中间经过哪些加工？
- 先选择报表，再选择该报表的一个表头列（如"利率"）。
- 系统自动定位该列对应的源表+源字段，并以图谱展示**字段级上游链路**：
  - 起点：报表该列直接取数的字段。
  - 逐层向上追溯每一跳的来源字段、所属存储过程、转换表达式。
  - 可在图谱上按 Schema/表名筛选、点击节点查看详情。

> 模式 4 与「影响分析」的字段级上游共用同一套图谱，区别在于起点由报表表头列自动确定，无需手动选表选字段。

## 常见问题速查

| 我想…… | 去哪个功能 |
|--------|-----------|
| 导入新的存储过程脚本 | 导入脚本 |
| 看某个存储过程用了哪些表 | 依赖表详情 |
| 看表之间的数据流向 | 血缘图 |
| 改某张表会影响哪些下游 | 影响分析（下游） |
| 某个字段的数据从哪来 | 影响分析（上游，字段级） |
| 某张表被哪些报表用了 | 报表影响分析 → 表级 |
| 报表某列最初来自哪个字段 | 报表影响分析 → 报表列溯源 |
| 某个口径在哪些报表出现 | 报表影响分析 → 口径 |

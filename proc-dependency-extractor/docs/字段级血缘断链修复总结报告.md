```java
// 新增: 候选表列集合构建（物理表查 DB 元数据 + 临时表用内联列定义）,
// 剔除无列信息的表, 防止"其他表都没有该列"误判为唯一命中
private Map<String, Set<String>> buildBareColumnCache(Map<String, String> aliasMap,
                                                       Map<String, List<String>> tempColumnDefs) {
    Map<String, Set<String>> cache = new HashMap<>();
    cache.putAll(buildDdlCache(aliasMap.values()));
    if (tempColumnDefs != null) {
        for (Map.Entry<String, List<String>> en : tempColumnDefs.entrySet()) {
            String tableShort = en.getKey();
            if (tableShort != null && aliasMap.containsValue(tableShort)) {
                Set<String> columns = cache.computeIfAbsent(tableShort, k -> new HashSet<>());
                if (en.getValue() != null) {
                    for (String col : en.getValue()) {
                        if (col != null) columns.add(col.toUpperCase());
                    }
                }
            }
        }
    }
    cache.values().removeIf(Set::isEmpty);   // 无元数据的表不参与唯一匹配
    return cache;
}

// 新增: 列名 → 表 唯一匹配（多重匹配返回 null, 不误归属）
private String matchFieldToTable(String field, Map<String, Set<String>> ddlCache) {
    if (field == null || ddlCache == null || ddlCache.isEmpty()) return null;
    String fieldUpper = field.toUpperCase();
    String matched = null;
    int matchCount = 0;
    for (Map.Entry<String, Set<String>> entry : ddlCache.entrySet()) {
        if (entry.getValue().contains(fieldUpper)) { matched = entry.getKey(); matchCount++; }
    }
    return matchCount == 1 ? matched : null;
}
```

```java
// 新增: 递归解包 ParenthesedSelect（AS (SELECT ...) / INSERT (SELECT ...) 形式, ≤5 层）
private PlainSelect unwrapPlainSelect(Select sel) {
    if (sel == null) return null;
    for (int i = 0; i < 5 && sel != null; i++) {
        Object body = sel.getSelectBody();
        if (body instanceof PlainSelect) return (PlainSelect) body;
        if (body instanceof ParenthesedSelect) {
            sel = ((ParenthesedSelect) body).getSelect();
            continue;
        }
        return null;
    }
    return null;
}
```

```java
// 新增: 剥离表名末尾的日期分区数字后缀
private String stripPartitionSuffix(String tableShort) {
    String s = tableShort;
    Matcher m = Pattern.compile("_(\\d+)+$").matcher(s);
    if (m.find()) { s = s.substring(0, m.start()); }
    while (s.endsWith("_")) { s = s.substring(0, s.length() - 1); }
    return (s.isEmpty() || s.length() < 3) ? null : s;
}
```

1. **部署纪律**：改代码后 `mvn test` 通过 ≠ 生效；必须 `mvn package` 并重启应用（P9 教训）。

3. **JSqlParser 4.9 已知坑**（均已修复）：
   - `AllTableColumns extends AllColumns` 继承关系导致 A.* 被吞
   - `ParenthesedSelect` 与 `PlainSelect` 的 CTAS 括号形式差异
   - 连续 2+ 空行导致 JOIN 链解析中断
   - `MySQLGroupConcat` 不继承 Function
   - `InExpression` 需单独遍历
4. **PowerShell 脚本坑**：中文注释需 UTF-8 BOM（否则 PS 5.1 按 GBK 误读导致闪退）；MySQL CLI `-e` 中反斜杠需双写；输出列为 TAB 分隔。
5. **元数据盲区意识**：DWA 自产表不在 xlsx 中时，裸列归属与影响分析数据源会产生不一致表现，需通过补录元数据统一。
